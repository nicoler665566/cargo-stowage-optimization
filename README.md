# Container Ship Stowage Optimization

Compare a first-fit loading baseline with a mixed-integer linear programming (MILP) model using synthetic vessel and container data.

## Technical approach

Generate reproducible data; analyze container and slot characteristics; optimize placement under capacity, refrigerated cargo, hazardous cargo and simplified balance constraints; coordinate planning, validation, revision and explanation with LangGraph.

## Technologies

Python, NumPy, pandas, SciPy MILP, matplotlib, LangGraph

## Getting started

Open the notebook and run cells in order. The optional LLM explanation requires an OpenAI API key configured locally. This simplified academic model is not a certified maritime safety system.

For notebooks, use a compatible Python/Jupyter environment and install the imported libraries. Original environment-specific paths may need local adjustment.
